Installing for the first time

Windows
If Windows says it protected your PC, choose More info then Run anyway. After that the app updates itself.
Android
Open the downloaded APK. If asked, allow your browser to install unknown apps. The app tells you when a new version is out.
Linux
Make the AppImage executable (chmod +x) and run it. It updates itself. The .deb is for Ubuntu and Debian.
